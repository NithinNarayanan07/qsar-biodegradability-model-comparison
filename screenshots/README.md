# Application previews

A single user-captured screenshot of actual BITS Virtual Lab execution is provided
in the final submission PDF, with private connection details concealed. The lab
screenshot and student identification remain in private submission artifacts and
are not included in this public repository.

Inside the lab, source commit `96c69bb` was downloaded because Git was unavailable.
A Python 3.12.7 virtual environment used the pinned dependencies, all five
classifiers were trained with metrics matching the README to four decimal places,
and the Streamlit app was opened in lab Firefox at `localhost:8501`.

The other images are application previews:

- `local-preview.jpg`: the current green interface and test-data summary.
- `faculty-test-data-guide.jpg`: the explanation of the training/test split.
- `faculty-metrics-guide.jpg`: full metric names and plain-language definitions.

Local and Community Cloud previews are not substitutes for the private BITS
execution screenshot in the final PDF. Final upload and submission in the
assignment portal are performed by the student.
